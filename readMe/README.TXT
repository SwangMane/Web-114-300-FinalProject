----- SCHOLAR ARENA MINIGAME -----

The idea of this game was to have the player and enemies health as 'letter grades'. A+ 100 health, A++ is 100+ health and so on downwards. 
The user one page load will see a UI that contains 3 colums, in the middle a 'start game' button. Once the start game button is clicked, the user is greated with the enemies name (randomly generated) and a few intro messages. After a few more seconds, a menu with a coin flip mini game appears in which the user must select 'heads' or 'tails' to determine their turn order.

After that, the game begins. Either the user or the enemy takes their turn.

--- TO PLAY THE GAME --- 

For users - 
  Click either damage /  block / heal

For enemies -
  There 'AI' (branching logic) will determine their move set.

--- TO END THE GAME ---

To win or lose the game the user or the enemy must either go below 59 health (F) 
  That is the only condition to complete the game
